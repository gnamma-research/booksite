# Daruri English typeface choices

The default remains the reader’s native book-serif stack:

`'Iowan Old Style','Palatino Linotype','Book Antiqua',Georgia,serif`

The two deliberately more distinct optional choices are **Source Sans 3** and **Lexend**. The internal saved-preference keys `source-serif` and `literata` are retained so older reader settings continue to resolve without a migration.

The official Google Fonts variable TrueType files are self-hosted and included in the complete offline package. Source Sans 3 provides normal and italic faces across weights 200–900. Lexend provides its normal variable face across weights 100–900.

Both families are distributed under SIL Open Font License 1.1. Full notices are in `OFL-Source-Sans-3.txt` and `OFL-Lexend.txt`. Source paths and Git blob identifiers are recorded in `ENGLISH-SOURCES.json`.
