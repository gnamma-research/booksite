Darūrī browser-only PDF experiment

This is an isolated, nonpublication investigation. It tests whether a regular browser can typeset real canonical Arabic and English passages as PDF bytes, without the print dialog or a PDF-generation server.

Ready. Publication sign-off is not implied.

The browser obtains only the same-origin source fixture and licensed Noto fonts. No personal notes, cookies, uploads, browser screenshots, privileged print commands or server-side PDF rendering are involved.
