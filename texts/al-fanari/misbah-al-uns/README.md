# Miṣbāḥ al-Uns R16 reader and continuation

Open `standalone.html` for the self-contained Arabic–English reader. It contains 664 passages, §§4.538–4.1141 and §§5.1–5.60, with language controls, search, bookmarks and optional notes.

The current draft reaches the inherited 85% source-page checkpoint. The reader does not yet contain the earlier master through §4.537. This package is therefore not fully cumulative. It is a first-pass electronic-source translation, not a critically collated edition.

`HANDOFF.md` records the exact next passage, provenance, limitations and preservation details. `R16_EDITORIAL_APPARATUS.md` separates the new editorial notes from continuous reading. `source/OpenITI-Misbah.txt` preserves the exact pinned Arabic witness. `variants/` holds excluded alternative drafting; it is not additional translation coverage.

The modular reader uses `index.html`, `reader.js`, `reader.css` and the JSON files. Serve these through HTTP when using the modular version. The portable version embeds its text and scripts.
