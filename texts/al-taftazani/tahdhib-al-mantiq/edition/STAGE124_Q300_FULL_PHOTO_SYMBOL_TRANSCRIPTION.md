**13 November 2026.** From original printed H1405 Qum p.300 photograph: **32 of 32 symbols directly read**, with Arabic classification and English translation. This is a one-print photographed source check, *not* authenticated manuscript collation.

## Source-checking limits

The published original provides handwritten-looking shorthand cells; direct reading of each code is separate from proving a modal logic relation. Both the prose and table count 9 invalid, 7 valid accepted, 16 valid unaccepted. The classification **ص غ م** must not be translated 'incorrect'.
