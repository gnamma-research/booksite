# al-Mustaṣfā · أبو حامد الغزالي

The Gnamma Research digital working edition of *al-Mustaṣfā min ʿIlm al-Uṣūl* lives here.

- `index.html` — responsive Arabic/English reader.
- `assets/` — JavaScript and styles; cross-book catalogue accessible from navigation.
- `data/reader.json` — working English/Arabic excerpt corpus with critical and bibliographical links.
- `editorial/` — passage register, bibliography, technical translation method, Hammad comparisons and editorial audit.
- `../../../arabic/full-arabic-pages.json` — shared full Arabic witness (also retained in its initial GitHub location for link stability).

This is **not** a finished full English translation. Read `editorial/EDITORIAL_STATUS.md` first.
