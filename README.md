# Gnamma Research — al-Mustaṣfā Reader

A mobile-first research reader for Abū Ḥāmid al-Ghazālī’s *al-Mustaṣfā min ʿIlm al-Uṣūl*.

**Editorial status:** Full Arabic digital witness and selected, independently translated English passages; **not a complete English translation** and **not a critically established Arabic edition**.

Arabic source: OpenITI `0505Ghazali.Mustasfa.Shamela0005459-ara1`, licensed [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/), attribution and noncommercial/share-alike requirements apply. Do not confuse machine transcription with a collated critical edition. The page numbers reflect its own base edition and are not automatically those of the uploaded Hammad English translation.

Hammad (1987) is used as a comparator and is not uploaded to this public repository. Supplementary interpretive work draws on source-cited academic literature.

Read the website `index.html` when GitHub Pages is enabled. Mobile deployment may require enabling GitHub Pages from this repository's branch in Settings → Pages.
