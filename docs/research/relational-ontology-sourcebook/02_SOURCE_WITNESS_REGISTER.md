# Source and witness register — v1, 31 October 2026

## Evidence conventions

READ-HTML = relevant original Arabic read in pagination-marked website transcription; not an independently checked facsimile. READ-PRINT = page-image collation, which is NOT yet completed here. CATALOGUED = bibliographic witness located but passages not read. OCR-UNSAFE = searchable copy demonstrably corrupt and not safe for verbatim citation. USER-PDF = text available from the user's supplied PDF. UNKNOWN = necessary witness not yet located. Source 'p.' in Spiker may refer to a different printed edition from a website's p.; do not silently equate. Do not attribute the whole HTML page to its catalogued author where it includes matn/sharḥ/marginal commentary.

## Citation reliability rules

1. Source webpages can be useful full contexts but are not print-collated. Correct source and status in every note.
2. An author's doubt ("fīhi taraddud") and objection are not conclusive endorsements.
3. Reported positions ("baʿḍuhum", "qīla", "fa-in qīla") must be tagged rather than silently adopted.
4. URLs to web PDF require screenshot verification if analyzed through web; current citations rely on Arabic HTML, not uninspected PDFs.
5. Keep long quotations out of public publication unless licensed or permission is established. Sourcebook records arguments with short precise excerpts plus links; fuller original Arabic can be handled in separately licensed research witnesses.
6. The most important open issue is whether a relational configuration of a bed is an actual dependent mode or merely conceptually formed—as different glosses in S02 appear to disagree. The answer is not settled by translating it as a 'relational form'.
