Detailed source recovery record

Original source location

Earlier work recorded the master files under the original Mac's ~/.codex/.chatgpt-projects/ project tree. They were not found in the connected GitHub repository or Project Library.

One-step source packaging: use the recovery script from a Terminal on the Mac that created the research. It locates the original project, verifies the named master files, generates a private ZIP preserving source files, and records SHA-256 checksums. See the instructions. It does not publish anything or alter the originals.

The package is for private transfer and audit. Rights and licenses must be checked before public deployment of any source texts.
