Verification levels

Attested: original OpenITI work and version identifiers exist in the selected release and their Git object hashes are recorded. Byte-matched local: a GNAMMA-hosted full text matches its source Git blob hash. Editorially provisional: individual manuscript, edition, internal hadith numbering, commentary dependency and textual-critical claims require additional comparison, even when a digital version was marked reviewed by OpenITI.

Read the source-verification register and structured corpus registry. The intellectual atlas preserves separately qualified book-to-book relationships; this corpus library does not manufacture those arrows from shared terminology.
